## 🏗️ System Architecture Philosophy

Modern full-stack engineering demands resilient decoupling, fast feedback loops, and robust observability:

```mermaid
graph LR
    subgraph Client["Frontend Layer (Client)"]
        UI["React / Next.js 14 App"]
        State["State Store & Caching"]
        WSClient["WebSocket Client"]
    end

    subgraph Gateway["API Gateway & Security"]
        Proxy["Reverse Proxy / Nginx"]
        Auth["JWT & RBAC Middleware"]
        RateLimit["Rate Limiter"]
    end

    subgraph Services["Backend Services"]
        API["Node / Express API Server"]
        Worker["Async AI / Analytics Worker"]
    end

    subgraph Data["Storage & Intelligence Layer"]
        DB[("PostgreSQL")]
        Cache[("Redis Cache")]
        AI["LLM & Vision Pipelines"]
    end

    UI --> Proxy
    WSClient <--> Proxy
    Proxy --> Auth --> RateLimit --> API
    API --> DB
    API <--> Cache
    API --> Worker
    Worker --> AI
```
